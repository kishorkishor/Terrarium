## What it means
1. **The mister has a hard ceiling of about 89.5 %RH** at the inside sensor, reached in under 2 minutes, and it is repeatable to 0.4 %. Misting longer adds droplets, not humidity. A burst cap of 2 to 3 minutes is enough for this box; the old 5 minute cap wastes water.
2. **The closed box barely dries.** With the room at 75 %RH, the inside falls only 1.7 % in 20 minutes. A decay time constant cannot be fitted from this run because the inside and outside air are too close. The earlier run today with one end open fell 5 % in 25 min.
3. **Temperature moves with the mist:** the inside warms 0.2 to 0.4 °C while the disc runs (the disc heats the water), then falls 0.5 °C below the start as the fog evaporates. The model must include temperature, or work in absolute humidity, which the brain already does.
4. **Consequence for the controller comparison:** in this room, with the lid closed and no fan, the on/off rules will mist perhaps once every few hours. There is little for any controller to do. To make the comparison meaningful, the box needs a drying path: the exhaust fan on a schedule, or a fixed vent gap. Decide this before the brain run.

## Model constants (for tools/brain/sim_box.py)
- k_mist (dry-air equivalent): 0.10 g/m³/s with this disc in the closed box, 0.17 in the afternoon run with the end open. Use 0.10 for the closed rig.
- Ceiling: the (1 − RH/100) factor alone does not explain a hard stop at 89.5 %; add condensation on the walls as a sink above about 88 %.
- Leak: too small to measure closed. Measure again with the vent or fan.
